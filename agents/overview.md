# Overview

## Domains

The fixed list of domains. Each one is used as a commit message prefix and to group notes. Add or rename a domain here in the same commit that first uses it.

| Domain | Covers | Notes |
| :- | :- | :- |

| `GUI` | User interface: Preferences, the home page, dialogs | [homepage.md](homepage.md) |
| `Agents` | Agent instructions and notes: `AGENTS.md`, `agents/` | |
| `Generic` | Generic tasks that don't belong to a single domain | |
